## Descrição do Projeto

Este projeto consiste em um site de venda de serviços, onde os usuários podem encontrar e contratar profissionais para realizar diversos tipos de serviços.


## 🛠️ Tecnologias 

- [Typescript](https://www.typescriptlang.org/)
- [React](https://pt-br.react.org/)
- [Node.js](https://nodejs.org/en/)
- [Java](https://www.java.com/pt-BR/download/manual.jsp)
- [MySQL](https://www.mysql.com/)

## Pré-requisitos

antes de comecar voce precisa ter instalado as seguintes ferramentas:
[Git](https://git-scm.com), [Node.js](https://nodejs.org/en/).
Alem disso ter um editor de codigo para trabalhar com o codigo como [VSCode](https://code.visualstudio.com/), tambem ter o [MySQL workbench](https://www.mysql.com/) rodando um servidor mysql e um banco de dados de acordo com projeto e o [Java](https://www.java.com/pt-BR/download/manual.jsp) na sua maquina.

## 🎲 Rodando Front-end
```js
// Clone o repositório para o seu ambiente de desenvolvimento local.
$  git clone https://github.com/guilhermefonseca2021/employee-management >

// abra a pasta
$  cd front end

// instale as dependencias
$  npm install

// Execute o servidor para que o site possa se comunicar com o backend.
$  npm run dev
```
